# Ananda Triharis Maroso — Portfolio

**Live at [portfolio-bukd.vercel.app](https://portfolio-bukd.vercel.app)**

A static portfolio of my product, AI, and technical-growth work. Every project gets
one page with three sections: Overview, Build, and Results.

Built with TypeScript, React and Next.js, styled with Tailwind CSS and plain CSS,
animated with Motion, and tested with Vitest.
